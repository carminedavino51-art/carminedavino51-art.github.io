Progetti

Radar Voli Napoli

Python · JavaScript · GitHub Actions

Mappa degli aerei che volano intorno all'aeroporto di Napoli Capodichino, aggiornata in automatico ogni 15 minuti con dati ADS-B pubblici.

  • Job schedulato su GitHub Actions: uno script Python scarica i dati da un'API pubblica, con una fonte di riserva se la prima non risponde
  • Raccolta dati lato server per aggirare il blocco CORS del browser; niente server né database, storico di 24 ore in un file JSON
  • Pagina web con mappa interattiva (Leaflet), statistiche, grafico del traffico nelle 24 ore e segnalazione dei codici di emergenza
  • Sicurezza: dati esterni mostrati senza rischio XSS e controllo di integrità SRI sulle librerie esterne
→ Apri il radar → Codice sorgente

Rain Run

Android · Kotlin · Room

Gioco endless-runner per Android ispirato al dinosauro offline di Chrome, sviluppato per l'esame universitario di Programmazione di Dispositivi Mobili.

  • Stato di gioco gestito con ViewModel e StateFlow, così il punteggio sopravvive ai cambi di configurazione
  • Record salvato in locale con Room (entity, DAO, database, repository) tramite funzioni suspend
  • Gestione del ciclo di vita: pausa automatica in onPause e ripresa in onResume
  • View Binding al posto di findViewById per un codice più pulito
→ Codice sorgente su GitHub

Laboratorio di sistemi embedded

C / C++ · PCTO

Progetto di alternanza scuola-lavoro (PCTO) all'ITIS E. Majorana: logiche di controllo su microcontrollori, interfacciamento con sensori e attuatori tramite I/O digitali e analogici.
